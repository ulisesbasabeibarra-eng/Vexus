
# Triatlon-2026
Robot Triatlón para Bonaerenses 2026 por parte de los Alumnos de 6° año. Campeones Región 2

- [@Ulises Basabe](https://github.com/ulisesbasabeibarra-eng)
- [@Facundo Dominguez](https://github.com/facundodominguez1)
- [@Ramiro Trejo](https://github.com/RamiiTrejo)


## Componentes 

1-Esp32 38 pines

1-Bateria 2s de 450mAh

1-Bateria 3s de 2200mAh

2-Driver de motores BTS7960

2-Motores Titán de 1000RPM

## Sensores
1-Regleta **QTR8a** [Datasheet]()

3-Sensores infrarrojos **TCRT5000** [Datasheet]()

5-Sensores **Sharp Gp2y0a02yk0f**: [Datasheet]()

-3 frontales

-2 laterales

## PCB

Este PCB fue realizado con el software de diseño libre y gratuito KiCad, el cual nos facilita el uso debido a su interfaz intuitiva 

En este se implemento el diseño doble faz y componentes SMD (como lo son capacitores, una resitencia y un regulador)
